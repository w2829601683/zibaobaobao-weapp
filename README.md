# 字宝宝 · 幼儿园识字小程序

> 给 3–6 岁小朋友学汉字的微信小程序。无后端、无云开发、个人主体可上线。

![status](https://img.shields.io/badge/status-MVP-success)
![platform](https://img.shields.io/badge/platform-微信小程序-1AAD19)
![license](https://img.shields.io/badge/license-MIT-blue)

## ✨ 它能做什么

- **4 大页面**：首页（分类）→ 学习（卡片）→ 小测验 → 我的进度
- **50+ 常用汉字**，按 7 个主题分组：动物、水果、食物、自然、数字、用品、身体
- **图字对照**：每个字配一张 emoji 卡通图、拼音和一句童趣解释
- **学习模式**：单字卡片 + 翻页/列表两种视图 + "我学会了"标记
- **小测验**：10 题看图选字，4 选 1，正确率 / 星星即时反馈
- **进度记录**：已学字、星星数、各分类完成度、答题正确率 —— 全部本地保存
- **激励机制**：每答对一题得一颗星，每个字最多三颗星，结算页有 emoji 反馈

## 🎯 设计取舍

| 选择 | 为什么 |
|---|---|
| 微信原生（不是 uni-app / Taro） | 个人开发者最简单、文档最完善、调试最快 |
| 本地存储（不是云开发） | 避免个人主体资质问题、零成本、零依赖 |
| emoji 占位图 | 不依赖网络图片、跨平台一致、可后期替换 |
| 跟读按钮 = 本地普通话音频 | 54 个 MP3 随代码包发布，无需云开发、网络或麦克风权限 |
| 单文件数据 (chars.js) | 字库小（50+），JSON 文件足够；后续可换成云端 |

## 🚀 5 分钟跑起来

### 1. 准备 AppID

如果你还没有：

1. 访问 [微信公众平台](https://mp.weixin.qq.com/wxopen/waregister?action=step1)
2. 注册「小程序」账号，选择「个人」主体
3. 实名认证后到「开发管理 → 开发设置」拿 **AppID**

如果你只想本地预览：

> 用微信开发者工具新建项目时选择 **「测试号」**，可以跳过注册直接试跑。

### 2. 填入 AppID

打开 `project.config.json`，把 `"appid": "请替换为你的 AppID"` 改成你自己的 AppID。

### 3. 用微信开发者工具打开

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 打开 → 选择「导入项目」→ 选择本目录 → 填入 AppID
3. 编译器会自动跑起来 → 右侧模拟器看到首页

### 4. 真机预览

点击开发者工具顶部 **「预览」** 按钮 → 弹出二维码 → 用手机微信扫码 → 在真机上跑起来。

## 📚 如何扩展

### 加新汉字

打开 `data/chars.js`，在 `chars` 数组里追加：

```js
{ char: '熊', pinyin: 'xióng', emoji: '🐻', category: 'animal', hint: '森林里的大块头' }
```

如果用到新分类，还要在 `categories` 数组里加一条。

### 替换 emoji 为真实图片

把 `emoji` 字段换成 `image: '/images/xxx.png'`，然后修改 `components/char-card/char-card.wxml`：

```xml
<view class="char-card__emoji">
  <image wx:if="{{ image }}" src="{{ image }}" mode="aspectFit" />
  <text wx:else>{{ emoji }}</text>
</view>
```

### 加新分类

1. `data/chars.js` 的 `categories` 数组加一项
2. 给该分类的字加 `category: '新分类ID'`
3. 首页会自动出现新分类卡片

### 本地普通话语音

项目已经包含 54 个普通话 MP3，位于 `assets/audio/`。点击汉字、拼音或「跟我读」都会播放对应字词的录音：

```js
const { speak } = require('../../utils/speech.js');
speak('猫');
```

播放使用 `wx.createInnerAudioContext()`，不依赖网络或云开发，也不会申请麦克风权限或录制用户声音。新增汉字时，需要同步添加 MP3 并在 `utils/speech.js` 的 `audioPaths` 中登记。

## ⚠️ 个人主体小程序的限制

这是个人开发者（无营业执照）能 / 不能做的事：

| ✅ 可以 | ❌ 不可以 |
|---|---|
| 工具类（识字、计算器） | 支付 / 收款 |
| 内容展示（电子书） | 视频 / 直播 |
| 学习类（题库、单词） | 社交（朋友圈、聊天） |
| 小游戏（休闲） | 医疗 / 金融 / 政务 |

如果想加被禁类目，需要注册「企业主体」或「个体工商户」。

## 🚢 上线发布

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 完善小程序信息（**名字、图标、简介、类目**）
2. 开发者工具点 **「上传」** → 填版本号 → 上传代码
3. 公众平台 → 版本管理 → 找到刚上传的版本 → **「提交审核」**
4. 等待 1–7 天审核（工具类通常 1–2 天）
5. 审核通过 → **「发布」** → 即可被搜索到

**审核小贴士**：
- 类目选「教育 → 婴幼儿教育」或「工具 → 学习工具」
- 简介里写明"适合 3–6 岁儿童"
- 如果用了 emoji 作图，简介里加一句"卡通配图"
